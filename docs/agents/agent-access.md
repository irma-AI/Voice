# What agents can reach

How an agent reaches each source it needs to work like an engineer, and what it may not do there. An agent looks here before saying it can't see something, and a source with no row is one it can't reach yet.

Access starts read-only; writing to a source is its own row with its own reason. Credentials follow `CLAUDE.md` § Hard rules 6, and production data stays stop-and-ask whatever a row says.

| Source | How an agent reaches it | Credential (name only, never the value) | May | May not |
|---|---|---|---|---|
| Tickets: Linear (team `VOI`, project `Voice`) | `linearis` CLI, installed by `scripts/cloud-tools.sh`; the edit hook `scripts/ticket-gate.js` and CI guard `ticket-required` read a ticket through Linear's API | `LINEAR_API_TOKEN` (in CI a GitHub secret of the same name, read-only, set by Petter; not checked: its scope has not been seen) | read, create, comment, label issues in the Voice project | delete issues; change other projects, teams, cycles or project settings |
| Code: GitHub, this repo | GitHub MCP tools in cloud sessions | the session's GitHub connection | read; push to the session's branch; open PRs; comment; turn on auto-merge (GitHub merges once CI passes) | merge a PR in a `CLAUDE.md` § Stop and ask area before Petter's answer; force-push to `main`; change repo settings |
| Model: Gemini API | requests to `generativelanguage.googleapis.com`; the cloud proxy injects the key | none in the session (proxy-injected); the app reads `GOOGLE_API_KEY`; not checked that Dokploy has it set | calls inside the spend caps (a monthly spend limit on the Google AI account, amount kept private; Petter's word, not seen) | raise caps, change the key, project or billing tier (`CLAUDE.md` § Stop and ask) |
| Hosting: Dokploy, project `Voice` | Dokploy API at the host the cloud environment's network policy allows; the cloud proxy injects the token | none in the session (proxy-injected) | read app status, deploy history and logs of the Voice project (apps `app` and `portal`, Postgres `portal-db`); set environment variables of the Voice app after Petter's go on a card, never reading a secret back into chat; set the update order (start-first) of apps `app` and `portal` and the stop wait (660 s) of `app` (VOI-121, Petter's go 2026-10-18; a later change to deploy settings needs a new go) | deploy (a merge to `main` deploys), change anything else in config, or touch any other project: the token reaches all projects, so this is a rule, not a scope |
